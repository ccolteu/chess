# Chess v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a playable Android chess app: human White vs depth-3 AI Black.

**Architecture:** Pure Kotlin `domain` + `engine`, Compose `ui/game` driven by `ChessViewModel`.

**Tech Stack:** Kotlin 17, Jetpack Compose, JUnit4, coroutines, AGP empty-activity template.

## Global Constraints

- Human is always White; AI is always Black.
- No chess libraries.
- Rules must be unit-tested without Android.
- Engine must only return a legal move.

## File map

- `domain/GameModels.kt` — Color, Piece, Square, Move, GameState
- `domain/Fen.kt` — parse/start position
- `domain/Rules.kt` — legal moves + apply
- `engine/Engine.kt` — search
- `ui/game/ChessViewModel.kt` — selection, AI turn
- `ui/game/GameScreen.kt` — board UI
